# 「マエバシ・ダイブ」副読本

街歩きRPG『マエバシ・ダイブ』を、地域団体のチームで遊ぶための副読本です。
A5判・全11ページ。ブラウザでページをめくって読めます。

## 公開のしかた（GitHub Pages）

1. GitHubで新しいリポジトリを作る（公開設定は Public）
2. このフォルダの中身をすべてアップロードする
   （`index.html` がリポジトリのいちばん上の階層に来るように）
3. リポジトリの **Settings → Pages** を開く
4. **Source** で `Deploy from a branch` を選び、`main` ブランチ / `/ (root)` を指定して Save
5. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## ファイル構成

```
index.html   … ページをめくって読むビューア
pages/       … 各ページの画像（JPEG・1118×1588px）
pdf/         … 印刷用PDF（1ページずつ＋全ページ通し）
.nojekyll    … GitHub Pagesの変換処理を止めるための空ファイル
```

## 差し替えるときは

`pages/` の画像を同じファイル名で上書きすれば、ビューアの表示も入れ替わります。
ページを増減する場合は `index.html` の中ほどにある `PAGES` の一覧に行を足し引きしてください。

## 入稿前にやること

- 裏表紙のQRコードを、元データ（高解像度）に差し替える
- 奥付の表記（発行・制作・後援）を確認する
- 印刷所に入れる場合は、天地左右に3mmの塗り足しを足した版に組み直す
